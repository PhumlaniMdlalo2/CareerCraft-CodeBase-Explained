HttpClient: Talking to the Backend

Configured in app.config.ts, HttpClient is injected into services to make API calls using the apiBaseUrl from environment config.

// Example from JobService
private http = inject(HttpClient);
private apiBaseUrl = environment.apiBaseUrl;

getOpenPositions() {
  return this.http.get<BackendJob[]>(`${this.apiBaseUrl}/jobs/findOpenPositions`);
}

State Management: Signals in Action

Services use Angular signals to manage state, making data reactive and efficient:

  • AuthService holds the current user (persisted to localStorage).
  • ApplicationService tracks applications and applied job IDs.
  • Components subscribe to signals to update the UI automatically.
Service State (Signal) ──▶ set(data) / update(fn) ──▶ UI Component auto-renders
        ▲
        └────── HttpClient response / user interaction

Authentication Flow: How Users Log In

  1. Signup/Login: AuthService posts to /jobseekers/create or /users/login.
  2. Fetch Profile: After login, it fetches role-specific data from /jobseekers/read/{userId} or /employers/read/{userId}.
  3. Route Guards: auth.guard.ts checks if the user is logged in; role.guard.ts checks the role (jobseeker/employer).
  4. Scoped Requests: Services like ApplicationService use the current user ID from AuthService to load user-specific data.
1. Form Submit ──▶ POST /users/login ──▶ Returns userId
2. Fetch Profile ──▶ GET /jobseekers/read/{userId} ──▶ Returns full profile
3. Save State ──▶ userSignal.set() + localStorage.setItem('careerwise_auth_user')
4. Navigate ──▶ auth.guard checks AuthService.isAuthenticated() ──▶ Load Dashboard

Simple Explanation

Imagine the frontend as a restaurant dining area and the backend as the kitchen:

  • Menu (API): The waiter (HttpClient) uses the menu (endpoints) to take your order (request).
  • Kitchen (Backend): Prepares the meal (processes data) and sends it back.
  • Plating (DTO Mapping): The waiter adds garnishes (computed fields) before serving.
  • Reservations (Auth): The host (AuthService) checks your reservation (login) and seats you (grants access).
  • Waitstaff (Signals): Busily update the menu board (UI) when the kitchen sends new info.

Everything connects through the service team (API) to give you a seamless dining experience! 🍽️

Key Takeaways

  • Frontend uses Angular signals for reactive state management.
  • DTO mapping isolates backend changes from the UI.
  • AuthService acts as the gateway for user-specific data.
  • Environment config ensures API URLs are centralized.
