Patterns

  • Standalone: standalone: true, import deps in imports: []
  • DI: private http = inject(HttpClient);
  • State: signal<T>(), computed(), asReadonly()
  • HTTP: this.http.get<T>(url) ? pipe(map(...), catchError(...))
  • Upload: FormData with 'file'
  • Download: { responseType: 'blob' }
  • Auth: Signals + localStorage (careerwise_auth_user)
  • Mapping: Backend DTO ? UI model in service layer

Must Know

  • API base: http://localhost:8080/api
  • All API calls go through services (never components directly)
  • Guards protect routes (auth/role)
  • Signals drive reactive UI
  • DTO/UI mapping isolates backend changes
