# Mission

## Goal
Teach the user about the Angular frontend: structure, how components/services work, routing, state, HTTP, guards, and how it consumes the backend.

## Scope
- Project structure (standalone components, layouts, pages, components, services, models, guards)
- Angular 20 patterns used (signals, inject, standalone)
- Routing and route protection (guards)
- HTTP with HttpClient, environment config, DTO/UI model mapping
- Auth state and localStorage
- Component composition and data flow
- Forms, UI patterns (Tailwind)

## Desired Outcome
Be able to explain and navigate the frontend, modify/add components, understand how data flows from API to UI.
