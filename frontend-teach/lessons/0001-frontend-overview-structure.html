0001 - Frontend Overview & Structure

Mission

Lesson Goal

Grasp the Angular frontend's architecture, entry points, folder organization, and core concepts like standalone components and signals.

Entry Points: Where the App Starts

  • client/src/main.ts: Bootstraps the Angular app.
  • client/src/app/app.config.ts: Configures providers (e.g., HttpClient, router) for dependency injection.
  • client/src/app/app.ts: Root component rendered in index.html.
  • client/src/app/app.routes.ts: Defines all application routes.

Folder Structure: The Project's Blueprint

The frontend is organized like a factory, with specialized departments:

Key Concepts: How It All Works

  • Standalone Components: No NgModules needed—import dependencies directly where used.
  • Signals: Reactive state management for efficient updates. Use signal() for state, computed() for derived values.
  • inject(): Simplifies dependency injection without constructor parameters in some cases.

Simple Explanation

Imagine the frontend as a restaurant:

  • Components: Dishes (e.g., a menu card, order button).
  • Services: Chefs handling orders (API calls) and kitchen logic.
  • Routes: Different sections (dining area, checkout) protected by guards (reservations required).
  • Signals: Waitstaff updating the menu board when the kitchen changes specials.

Everything connects to serve customers (users) seamlessly! 🍽️
