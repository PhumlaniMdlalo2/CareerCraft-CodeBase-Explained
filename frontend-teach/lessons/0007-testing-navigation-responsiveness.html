Navigation: Moving Between Pages

Angular provides two ways to navigate:

  • Declarative (RouterLink): HTML links in templates. Used for menus, buttons, and cards.
  • Programmatic (Router Service): JavaScript navigation in components/services.
// RouterLink Example (template)


  Dashboard
  Search Jobs



// Router Service Example (component)
constructor(private router: Router) {}

navigateToJob(jobId: string) {
  this.router.navigate(['/jobs', jobId], { queryParams: { view: 'details' } });
}

Testing: Ensuring Quality

Angular tests use TestBed to create test environments:

  • Component Tests: Verify template rendering and interactions.
  • Service Tests: Mock dependencies and test methods.
  • Integration Tests: Test full user flows.
// Example Component Test
specify('DashboardComponent', () => {
  const fixture = TestBed.createComponent(DashboardComponent);
  const component = fixture.componentInstance;
  
  component.recommended.set(mockJobs);
  fixture.detectChanges();
  
  expect(fixture.debugElement.query(By.css('.job-card'))).toBeTruthy();
});

Run tests with: npm test in the client directory.

TESTING WORKFLOW
1. Describe test scenario (describe block)
2. Set up TestBed → compile component/service
3. Arrange: inject dependencies, set inputs
4. Act: call method or trigger event
5. Assert: verify output/state

Example:
TestBed.createComponent(DashboardComponent)
  .overrideTemplate(DashboardComponent, '

  .overrideProviders([{provide: JobService, useValue: mockService}])
  .compileComponents();

Quick Checklist

  • Navigation: Use RouterLink for menus, Router for logic.
  • Responsive: Apply Tailwind breakpoints consistently.
  • Testing: Test components, services, and integration flows.
  • Best Practices: Follow existing patterns in the codebase.

Simple Explanation

Imagine a hotel lobby:

  • Navigation: Signs pointing to rooms (routes), elevators (Router) to move between floors.
  • Responsive Design: Rooms adapt—single bed on mobile (phone), double bed on desktop (large screen).
  • Testing: Housekeepers checking every room before guests arrive (automated tests ensure quality).

Everything works together to give guests a smooth stay! 🏨
