Forms: Data Collection

Forms are built using Angular's template-driven (simple forms) and reactive (complex forms) approaches. Examples:

  • Login/Signup: auth-layout pages use reactive forms with validation.
  • Job Posting: Multi-step form in employer-job-create.page.ts uses reactive forms with custom validators.

Use reactive for complex validation and dynamic forms

Key Tips: Use FormControl, FormGroup, and Validators for reactive forms. Keep logic in components, but complex validation in services.

UI Components: Reusable Building Blocks

Components are standalone Angular modules imported where needed:

  • job-card.component.ts: Displays job details with company logo and apply button.
  • header.component.ts and sidebar.component.ts: Navigation and layout structure.
  • toast.component.ts: Shows success/error messages using signals for state.

Styling with Tailwind CSS

Tailwind's utility-first CSS is used for rapid UI development. Examples from the codebase:

  • bg-white rounded-2xl shadow-sm: Card styling.
  • text-stone-900: Consistent text color.
  • grid grid-cols-3 gap-4: Responsive job grid.

Global styles (e.g., fonts, base colors) are in client/src/styles.css. Component-specific styles are inline or in separate CSS files.

Best Practices

  • Component Patterns: Use standalone components with signals for state.
  • API Calls: Keep HTTP logic in services, not components.
  • DTO Mapping: Convert backend data to UI models for clean templates.
  • Route Protection: Use guards to restrict access by role/auth status.

Simple Explanation

Imagine building a restaurant:

  • Forms: Order slips (customers input requests).
  • Components: Menu items (reusable dishes like job cards).
  • Tailwind: Chef's uniform (consistent styling across all staff).

Everything works together to serve customers (users) efficiently! 🍽️
