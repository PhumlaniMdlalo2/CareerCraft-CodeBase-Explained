# Mission

## Goal
The user wants to understand how the backend is consumed and how everything connects in this codebase.

## Scope
- Understand the backend architecture (Spring Boot + JPA/Hibernate)
- See how controllers, services, repositories, domain models, and factories work together
- Understand the API layer and what endpoints exist
- Understand how the Angular frontend consumes the backend (API calls, models, services, flow)
- Map the full request flow from frontend UI action through backend to database and back
- Identify key integration points, data contracts, and how the pieces connect

## Desired Outcome
After completing lessons in this workspace, the user should be able to:
1. Trace a typical request (e.g., creating a job, applying for a job) end-to-end
2. Explain the backend layering and responsibilities
3. Understand how the frontend calls backend APIs and maps responses to models
4. Know where to look to extend or modify functionality
