Resume Upload/Download: File Handling

job-seeker.service.ts manages resume operations using Angular's HTTP client:

  • Upload: Sends POST /api/jobseekers/{userId}/resume with FormData containing the file. Backend stores it server-side.
  • Download: Requests GET /api/jobseekers/{userId}/resume with responseType: 'blob'. Creates a temporary object URL and triggers a browser download.
// Upload Example
uploadResume(userId: string, file: File): Observable<BackendJobSeekerFull> {
  const formData = new FormData();
  formData.append('file', file);
  return this.http.post<BackendJobSeekerFull>(
    `${this.apiBaseUrl}/jobseekers/${userId}/resume`, 
    formData
  );
}

// Download Example
downloadResume(userId: string): Observable<void> {
  return this.http.get(
    `${this.apiBaseUrl}/jobseekers/${userId}/resume`, 
    { responseType: 'blob' }
  ).pipe(
    tap(blob => {
      const url = window.URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = 'resume.pdf';
      a.click();
      window.URL.revokeObjectURL(url);
    })
  );
}
RESUME UPLOAD/DOWNLOAD FLOW
Upload Process:
├─ User selects file → 
├─ Service creates FormData → formData.append('file', file)
├─ POST /api/jobseekers/{userId}/resume
├─ Backend saves file, returns { success: true }

Download Process:
├─ Service GET /api/jobseekers/{userId}/resume?responseType=blob
├─ RxJS tap creates object URL → window.URL.createObjectURL(blob)
├─ Create anchor element → a.href = url; a.download = 'resume.pdf'
├─ a.click() → browser download
└─ Cleanup: window.URL.revokeObjectURL(url)

Advanced State Management with Signals

Services expose readonly signals for reactive state sharing:

  • ApplicationService: applicationsSignal (array), appliedJobIdsSignal (Set for O(1) lookups)
  • AuthService: userSignal (persisted to localStorage)
// Service Example
private applicationsSignal = signal<Application[]>([]);
private appliedJobIdsSignal = signal<Set<string>>(new Set());

// Expose readonly access
applications = this.applicationsSignal.asReadonly();
appliedJobIds = this.appliedJobIdsSignal.asReadonly();

// Component Usage
// Access in template: {{ appliedJobIds().has(jobId) }}

├─ appliedJobIds = this.appliedJobIdsSignal.asReadonly()

Error Handling: Graceful Failures

  • HTTP Errors: Services use catchError to handle API failures, returning user-friendly messages.
  • Auth Errors: AuthService normalizes network/server errors into consistent formats.
  • UI Feedback: Components display toast notifications or inline errors using signals.
// Example Error Handling
this.http.post(...).pipe(
  catchError(error => {
    this.toastService.showError('Upload failed. Try again.');
    return EMPTY;
  })
);
ERROR HANDLING FLOW
Service Call → HttpClient → Response
   ↓            ↓            ↓
   Success     → map() → update signal → UI render
   Error       → catchError() → show toast → log to console
   NetworkErr → catchError() → show "Connection failed"

Debugging Tips: Finding Issues Fast

  1. Network Tab: Inspect /api/* requests for URLs, payloads, and responses.
  2. Console: Log service method entries/exits and critical state changes.
  3. localStorage: Check careerwise_auth_user for auth state issues.
  4. Angular DevTools: Inspect component hierarchies, signals, and state (if available).
  5. Source Maps: Ensure TypeScript errors map to original source code.
DEBUGGING STEPS
1. Open Chrome DevTools → Network tab
   └─ Check /api/* requests: URL, payload, response
2. Console tab → Search for errors, log() output
3. Application → Local Storage → careerwise_auth_user
4. Angular DevTools (if available) → Inspect signals
5. Source Maps → Verify TypeScript line numbers match
6. Network tab → Save response as HAR for debugging

Knowledge Check

6. Active Recall: What is the purpose of appliedJobIdsSignal in ApplicationService, and why is it a Set instead of an array?

Click to reveal answer
  • Purpose: To track which job IDs the current user has applied to for quick lookup.
  • Set vs Array: Set provides O(1) lookup/add/remove operations, while array would be O(n) for checking membership.
