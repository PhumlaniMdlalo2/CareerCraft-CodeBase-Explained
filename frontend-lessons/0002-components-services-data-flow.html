Service Pattern: Fetching Data

Services are singletons that centralize API logic. They use HttpClient to call backend endpoints and map responses to UI models.

@Injectable({ providedIn: 'root' })
export class JobService {
  private http = inject(HttpClient);
  private apiBaseUrl = environment.apiBaseUrl;

  getOpenPositions(): Observable<Job[]> {
    return this.http.get<BackendJob[]>(`${this.apiBaseUrl}/jobs/findOpenPositions`).pipe(
      map(backendJobs => backendJobs.map(bj => this.mapJob(bj)))
    );
  }

  private mapJob(backendJob: BackendJob): Job {
    return {
      id: backendJob.jobId!,
      title: backendJob.title,
      company: backendJob.employer?.companyName || 'Unknown Company',
      // ... other fields
    };
  }
}

Key points: Dependency injection (inject()), environment config, RxJS pipe and map for data transformation.

Component Pattern: Rendering Data

Standalone components import dependencies directly and use signals for reactive state.

@Component({
  selector: 'app-dashboard',
  standalone: true,
  imports: [CommonModule, RouterLink, JobCardComponent],
  template: `
    <div *ngFor="let job of recommended()">
      <app-job-card [job]="job" />
    </div>
  `
})
export class DashboardComponent implements OnInit {
  private jobService = inject(JobService);
  recommended = signal<Job[]>([]);

  ngOnInit() {
    this.jobService.getOpenPositions().subscribe(jobs => this.recommended.set(jobs));
  }
}

Key points: inject() for services, signal() for state, *ngFor for rendering lists.

Simple Explanation

Imagine ordering food at a restaurant:

  • Menu (Component): You see dishes (job listings) presented nicely.
  • Waiter (Service): Takes your order (API call) and communicates with the kitchen (backend).
  • Kitchen (Backend): Prepares the meal (processes data) and sends it back.
  • Waiter Returns: Delivers the food (mapped data) to your table.
  • You Enjoy (UI): The meal is exactly what you ordered, thanks to the waiter's translation!

Components and services work together to deliver data seamlessly! 🍽️

Knowledge Check (Multiple Questions)

1. Active Recall: Why do we use standalone components instead of NgModules in this project?

Click to reveal answer
  • Simpler architecture: No need to maintain NgModule declarations. Components import their own dependencies directly.

2. Active Recall: What is the difference between a backend DTO and a frontend UI model?

Click to reveal answer
  • DTO: Raw data shape returned by the API (e.g. nested objects, raw dates).
  • UI Model: Clean, UI-ready data shape with computed fields (like relative dates, initials, colors).

3. Active Recall: How does a component access an Angular service using modern syntax without constructor injection?

Click to reveal answer
  • Using the inject() function: private jobService = inject(JobService);

4. Active Recall: Why do we use signal() instead of raw variables for component state?

Click to reveal answer
  • Signals provide fine-grained reactivity, notifying the template to re-render automatically when the value updates without manual change detection.
